## 1. Project Overview

The Garden Exchange Database is a relational database designed to support LocalHarvest, a community garden organisation. It manages gardeners, garden plots, crops, planting records, harvests, produce contributions, members, produce requests and collection days.

## 2. Technologies Used

- MySQL — database management
- MySQL Workbench — database design and SQL execution
- Python — application script
- GitHub — version control and team collaboration

## 3. Repository Structure

- `database/` — database creation and sample data scripts
- `queries/` — SQL queries
- `application/` — Python application
- `design/` — ERD and relational schema
- `testing/` — test cases and results

## 4. Setup Instructions

1. Install MySQL and Python.
2. Create the Garden Exchange database using the supplied SQL scripts.
3. Insert the sample data.
4. Configure the application's database connection using your local environment variables.
5. Install the dependencies listed in `application/requirements.txt`.
6. Run the Python application and verify the query outputs.
